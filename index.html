模型与 API 中心

每个平台独立保存密钥。密钥只进入 sessionStorage，关闭浏览器后自动清除。

纯 HTML 直接调用 API 时，平台必须允许浏览器跨域请求。若出现 CORS 错误，需要使用平台提供的浏览器 SDK 或一个很小的安全代理；不要把长期密钥写死在 HTML 文件中。
